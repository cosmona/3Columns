# 3-column preview card component

Solución al reto **3-column preview card component** de [Frontend Mentor](https://www.frontendmentor.io): tres tarjetas de tipos de coche (Sedans, SUVs y Luxury), cada una con su color, icono, texto y botón.

## Cómo verlo

Abre `index.html` en el navegador. No necesita instalar nada.

## Detalles

- Diseño *mobile first*: en móvil (375 px) las tarjetas van en columna y en escritorio (1440 px) en fila
- Colores definidos como variables CSS a partir de la guía de estilo (`style-guide.md`)
- Fuentes [Lexend Deca](https://fonts.google.com/specimen/Lexend+Deca) y [Big Shoulders Display](https://fonts.google.com/specimen/Big+Shoulders+Display)

## Estructura

```
index.html
css/style.css
images/          # iconos y favicon
style-guide.md   # colores, tipografía y medidas del reto
```
